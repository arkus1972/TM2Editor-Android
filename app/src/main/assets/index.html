TM-2 Editor

Roland TM-2 backup editor

Edit kits, effects, sounds, trigger settings and system settings of a TM-2 backup file. Your original file is never changed — saving always creates a new backup.

  1. On the module: BACKUP SAVE to the SD card.
  2. Open ROLAND/TM-2/Backup/BKUP-xxx.TM0 from the card (card reader or a copy on the phone).
  3. Edit, then Save. Put the new file in ROLAND/TM-2/Backup on the card.
  4. On the module: BACKUP LOAD.
